# ⚖️ Sistema Inteligente de Triagem e Análise Jurídica com IA

## 📌 Sobre o Projeto

Este projeto consiste em um sistema inteligente desenvolvido com Python e Streamlit que integra:

- Triagem automática de processos jurídicos com Inteligência Artificial;
- Classificação inteligente de processos;
- Dashboard analítico com visualização de dados;
- Geração de insights estratégicos utilizando IA Generativa.

A aplicação foi desenvolvida como atividade prática de Inteligência Artificial, unindo conceitos de:
- NLP (Processamento de Linguagem Natural);
- IA Generativa;
- Análise de Dados;
- Visualização de Informações;
- Automação Jurídica.

---

# 🚀 Funcionalidades

## 📋 Triagem Inteligente de Processos

O sistema recebe processos jurídicos em formato JSON e utiliza IA para realizar automaticamente:

- Classificação da categoria jurídica;
- Definição de prioridade processual;
- Análise de complexidade;
- Avaliação de risco financeiro;
- Geração de rascunho jurídico inicial.

### Exemplo de saída da triagem

```json
{
  "processo": "5000001-32.2026.4.05.8200",
  "categoria": "Previdenciário",
  "prioridade": 4,
  "complexidade": "Alta",
  "risco_financeiro": "Médio",
  "resposta_rascunho": "Recomenda-se análise detalhada da documentação e acompanhamento prioritário."
}
